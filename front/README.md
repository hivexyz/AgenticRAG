# Gradio 界面使用指南

## 概述

Gradio 界面为 AgenticRAG 系统提供了一个直观的 Web 界面，用户可以通过浏览器与系统进行交互，无需编写代码。

## 功能特性

### 1. AgenticRAG 问答
- 智能问答对话
- 实时显示答案和质量分数
- 查询分析和检索结果展示
- 可配置的检索参数
- 对话历史管理

### 2. 查询分析
- 分析查询类型和复杂度
- 提取关键词
- 推荐检索策略

### 3. 文档管理
- 上传新文档
- 查看文档列表
- 删除文档

### 4. 系统状态
- 健康检查
- API 信息查看

## 快速开始

### 1. 安装依赖

```bash
uv sync --extra dev
```

### 2. 启动后端服务

首先需要启动 FastAPI 后端服务：

```bash
python main.py
```

后端服务将在 `http://localhost:8000` 启动。

### 3. 启动 Gradio 界面

在新的终端窗口中启动 Gradio 界面：

**Windows:**
```bash
start_gradio.bat
```

**Linux/Mac:**
```bash
python front/run.py
```

Gradio 界面将在 `http://localhost:7860` 启动。

### 4. 访问界面

在浏览器中打开 `http://localhost:7860` 即可使用界面。

## 界面说明

### AgenticRAG 问答标签页

这是主要的问答界面，包含以下组件：

#### 左侧区域
- **对话历史**: 显示用户与 AI 的对话记录
- **输入框**: 输入您的问题
- **发送按钮**: 提交问题
- **清除历史按钮**: 清除对话历史

#### 右侧区域
- **设置面板**:
  - 最大检索次数: 控制 AgenticRAG 最多执行多少次检索（1-5）
  - 显示详细信息: 是否显示查询分析和检索结果

- **答案信息面板**:
  - 答案: AI 生成的答案
  - 质量分数: 答案的质量评分（0-1）

- **详细信息面板**:
  - 查询分析: 显示查询的类型、复杂度、关键词等
  - 检索结果: 显示检索到的相关文档

### 查询分析标签页

用于单独分析查询，不执行检索：

- **输入查询**: 输入要分析的查询文本
- **分析按钮**: 执行分析
- **分析结果**: 显示分析结果，包括：
  - 查询类型（factual, conceptual, comparison, how_to, other）
  - 复杂度（low, medium, high）
  - 关键词列表
  - 搜索范围（narrow, medium, broad）
  - 建议的检索数量
  - 是否需要重排序
  - 分析说明

### 文档管理标签页

用于管理向量数据库中的文档：

#### 上传文档
- **文档标题**: 输入文档标题
- **文档内容**: 输入文档内容
- **元数据**: 可选，输入 JSON 格式的元数据
- **上传文档按钮**: 提交文档

#### 文档列表
- **刷新文档列表按钮**: 获取最新的文档列表
- **文档列表**: 显示所有文档的 ID、标题和创建时间

#### 删除文档
- **文档 ID**: 输入要删除的文档 ID
- **删除文档按钮**: 执行删除操作

### 系统状态标签页

用于检查系统健康状态和查看 API 信息：

#### 健康检查
- **检查健康状态按钮**: 检查 API 和 AgenticRAG 的状态
- **健康状态**: 显示系统各组件的状态

#### API 信息
- 显示应用名称、版本、API 基础 URL 等信息

## 使用示例

### 示例 1: 基本问答

1. 在 "AgenticRAG 问答" 标签页中
2. 在输入框中输入问题："什么是人工智能？"
3. 点击 "发送" 按钮
4. 查看生成的答案和质量分数
5. 在右侧查看查询分析和检索结果

### 示例 2: 多轮对话

1. 提问："机器学习有哪些类型？"
2. 等待回答
3. 继续提问："监督学习和无监督学习有什么区别？"
4. 系统会基于之前的对话上下文回答

### 示例 3: 调整检索参数

1. 在设置面板中，将 "最大检索次数" 调整为 3
2. 提问一个复杂的问题
3. 观察系统是否执行了多次检索以提升答案质量

### 示例 4: 上传文档

1. 切换到 "文档管理" 标签页
2. 填写文档标题："Python 基础教程"
3. 输入文档内容："Python 是一种高级编程语言..."
4. 点击 "上传文档" 按钮
5. 查看上传结果
6. 点击 "刷新文档列表" 查看新上传的文档

## 配置选项

在 `.env` 文件中可以配置以下参数：

```env
# API 配置
API_BASE_URL=http://localhost:8000

# Gradio 配置
GRADIO_SERVER_NAME=0.0.0.0
GRADIO_SERVER_PORT=7860
GRADIO_SHARE=false
```

### 参数说明

- `API_BASE_URL`: 后端 API 的基础 URL
- `GRADIO_SERVER_NAME`: Gradio 服务器地址
- `GRADIO_SERVER_PORT`: Gradio 服务器端口
- `GRADIO_SHARE`: 是否创建公共链接（用于分享）

## 故障排查

### 问题: 无法连接到 API

**可能原因**:
- 后端服务未启动
- API 地址配置错误

**解决方案**:
1. 确认后端服务已启动: `python main.py`
2. 检查 `.env` 文件中的 `API_BASE_URL` 配置
3. 在浏览器中访问 `http://localhost:8000/docs` 确认 API 可用

### 问题: 查询失败

**可能原因**:
- Milvus 服务未连接
- 向量数据库中没有相关文档
- OpenAI API 密钥未配置

**解决方案**:
1. 检查系统状态标签页中的健康检查结果
2. 上传一些文档到向量数据库
3. 检查 `.env` 文件中的 OpenAI API 配置

### 问题: 质量分数过低

**可能原因**:
- 检索的文档不相关
- 查询分析不准确

**解决方案**:
1. 增加 "最大检索次数" 参数
2. 上传更多相关的文档
3. 使用 "查询分析" 功能了解查询特点

### 问题: Gradio 界面无法启动

**可能原因**:
- 端口被占用
- 依赖未安装

**解决方案**:
1. 修改 `.env` 文件中的 `GRADIO_SERVER_PORT`
2. 确认已安装所有依赖: `uv sync --extra dev`
3. 检查是否有其他程序占用了 7860 端口

## 高级功能

### 流式输出

当前版本使用同步查询，未来将支持流式输出，实时显示查询过程中的中间结果。

### 自定义配置

可以通过修改 `front/config.py` 文件来自定义界面配置：

```python
# 界面配置
APP_TITLE = "AgenticRAG 智能问答系统"
APP_DESCRIPTION = "基于 LangGraph 的智能体驱动的 RAG 系统"
APP_VERSION = "1.0.0"

# 聊天配置
DEFAULT_MAX_RETRIEVALS = 2
DEFAULT_TEMPERATURE = 0.7
DEFAULT_TOP_K = 10
```

## 开发说明

### 项目结构

```
front/
├── __init__.py       # 模块初始化
├── app.py           # Gradio 主界面
├── config.py        # 配置文件
├── api_client.py    # API 客户端
└── run.py          # 启动脚本
```

### 扩展功能

如需添加新功能，可以：

1. 在 `api_client.py` 中添加新的 API 调用方法
2. 在 `app.py` 中创建新的界面类
3. 在 `create_interface()` 函数中添加新的标签页

## 注意事项

1. 确保后端服务已启动后再启动 Gradio 界面
2. 首次使用前，建议先上传一些文档到向量数据库
3. 质量分数和检索次数可以根据实际需求调整
4. 对话历史在刷新页面后会清除，如需持久化需要额外实现
